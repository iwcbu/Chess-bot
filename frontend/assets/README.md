# Chess SVG Pieces

These SVGs are square `100 x 100` assets with `viewBox="0 0 100 100"`, so the aspect ratio is 1:1.

They do not include a background rectangle, so the background is transparent by default.

Files included:
- white_king.svg, white_queen.svg, white_rook.svg, white_bishop.svg, white_knight.svg, white_pawn.svg
- black_king.svg, black_queen.svg, black_rook.svg, black_bishop.svg, black_knight.svg, black_pawn.svg
- chess-pieces-sprite.svg for `currentColor` usage
